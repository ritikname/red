# Lal Kitab Deterministic

A production-ready offline Android app implementing a deterministic astrology engine for the 1942 and 1952 Lal Kitab.

## Features
- Full Offline operation. No cloud APIs.
- Deterministic Rule Engine parsing base rules, exceptions, and contradictions.
- Enforces strict 1952 priority over 1942 rules.
- Contains UI screens for Jetpack Compose: Kundali Entry, Rule Result, Rule Audit, Chat query, and Source Browser.
- Pre-populated Room database from raw JSON sources.

## Current Build Note
The codebase is fully functional and successfully builds.
Both debug and release APKs can be generated by running:
`./gradlew assembleDebug` or `./gradlew assembleRelease`.

## Installation & Setup

1. **Crucial Step**: You MUST obtain the source JSON files from the provided Google Drive link.
2. Place `lal_kitab_rules_1952_validated.json` and `lal_kitab_rules_1942_validated.json` inside the `app/src/main/assets/` folder.
3. Build the app using `./gradlew assembleRelease`.
4. If you fail to include the files, the application will display an explicit critical error on launch rather than failing silently.

Once built, the APK will be located in the root of the repository as `LalKitab-release.apk` (which has been committed to version control so you can download it directly from GitHub), or under `app/build/outputs/apk/release/app-release-unsigned.apk` if you rebuild it locally.
